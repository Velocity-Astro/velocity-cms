# @velocity-astro/cms-db

SQLite and libSQL storage for Velocity CMS: tables, migrations and the repositories cms-core asks for.

Part of [Velocity CMS](https://github.com/Velocity-Astro/velocity-cms), a content management system for Astro sites. A site installs `@velocity-astro/cms-astro`, which brings the rest:

```sh
npx velocity-cms init
```

Docs: https://docs.deployvelocity.com/cms/
